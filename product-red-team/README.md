# Product Red Team

An adversarial product due-diligence skill for deciding whether an idea deserves more investment.

It answers:

> Should we build this at all, and what is the cheapest evidence that could change the decision?

## Structure
- `SKILL.md` — executable skill
- `doctrine.md` — principles and anti-patterns
- `workflow.md` — state machine
- `epistemology.md` — claims and evidence
- `research-policy.md` — research rules
- `decision-model.md` — information value and investment thresholds
- `scoring.md` — prioritization heuristics
- `experiments.md` — experiment design
- `kill-criteria.md` — kill/pivot/pause rules
- `interrogation.md` — questioning protocol
- `prompts/` — domain-specific attacks
- `agents/` — Prosecutor / Defender / Judge
- `templates/` — persistent decision artifacts
