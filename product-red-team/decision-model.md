# Decision Model

Let `I` = decision impact, `P` = probability new information changes the decision, `V` = value of making the better decision, `C` = information cost.

`EVSI ≈ I × P × V`

`Information ROI = EVSI / C`

This is a prioritization heuristic, not financial precision.

The more irreversible the next action, the stronger the evidence requirement. If a cheap experiment dominates another round of reasoning, stop grilling and run the experiment.
