# Epistemology

## Claim Types
| Type | Meaning |
|---|---|
| FACT | independently supported observation |
| FOUNDER_ASSERTION | founder-supplied but not independently verified |
| ASSUMPTION | proposition that must be true |
| INFERENCE | conclusion derived from evidence |
| JUDGMENT | strategic interpretation |

Never silently convert one type into another.

## Evidence Dimensions
Evaluate reliability, directness, recency, sample size, behavioral vs stated evidence, independence, reproducibility, and segment relevance.

## Evidence State
`SUPPORTED`, `PARTIALLY_SUPPORTED`, `UNSUPPORTED`, `CONTRADICTED`, `UNKNOWN`.
